# Dark Mode Implementation Plan

**Goal:** Restore complete iOS appearance support with persisted System, Light, and Dark choices and simulator evidence for every production surface.

**Approach:** Reuse `themeAtom`, `Appearance`, and the existing theme hook. Centralize semantic colors, apply the saved preference before rendering routes, then replace hardcoded neutral colors in vertical surface slices. Use native iOS appearance handling for tabs, sheets, controls, alerts, and menus.

## Approved test seams

- `hooks/useThemeColor.ts`: public palette lookup for the effective iOS appearance
- `libs/preferences.ts`: public preference load, save, reset, and appearance application behavior
- App routes and shared components: user-visible Light and Dark rendering verified through tests where stable and through iPhone Simulator inspection
